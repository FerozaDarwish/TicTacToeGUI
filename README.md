# Tic-Tac-Toe 🎮

A Tic-Tac-Toe game developed using C#, .NET and Avalonia UI.

## Features
- Two-player game (X and O)
- Interactive game board
- Automatic winner detection
- Draw detection
- Restart game

## Technologies
- C#
- .NET
- Avalonia UI

This project was created as part of my learning journey in C# and .NET development.
